# 어워드 사이트 리뷰 저널 — 색인

한 줄 = 리뷰 하나. 태그로 검색해서 레퍼런스를 다시 찾는 파일입니다.

형식: `날짜 | 사이트명 | 폴더 | 사용자 한줄평 | 스타일 태그 | 업종 태그 | 인터랙션 태그`

세 태그 축의 용도:
- **스타일** — "미니멀한 디자인 하려는데 참고작 줘" 같은 무드 검색
- **업종** — "커머스 레퍼런스만" 같은 도메인 검색
- **인터랙션** — "360도 회전 좋았던 데 어디였지" 같은 효과 검색
