# 맑은물에 ERP — AI 어시스턴트 프로토타입

맑은물에 홀딩스 식품제조 통합 ERP(el-bigs)에 붙는 **AI 어시스턴트**의 동작 프로토타입.
빌드 없음 · 의존성 없음. 정적 HTML/CSS/JS만으로 동작한다.

기획: `맑은물에ERP_AzureOpenAI_AI어시스턴트_MVP` · 디자인: 삼성화재 SFUXC 디자인 가이드 기반 리디자인(Figma)

## 화면

| 파일 | 내용 |
|---|---|
| `index.html` | ERP 홈 대시보드 (랜딩). 법인 탭 · 매출/영업이익 KPI · 매출추이 · 오늘의 알림 · 최근 출고 |
| `chat.html` | AI 어시스턴트 전체화면 챗 |
| `home.js` | 홈 대시보드 + 슬라이드 챗 패널 + 딥링크 전환 |
| `app.js` | 전체화면 챗 로직 |
| `style.css` | 공용 스타일 |

## 이중 진입 흐름

기획서의 UI 원칙 — **딤드 오버레이가 아니라 기존 컨테이너를 옆으로 밀어내는 슬라이드 방식**을 그대로 구현했다.

1. **상단 GNB `✨ AI 어시스턴트`** → 우측 430px 챗 패널이 도킹되고 뒤의 대시보드가 밀려 좁아진다 (딤 없음).
   모바일 폭에서는 전체화면(`chat.html`)으로 전환한다.
2. **좌측 LNB `AI 어시스턴트`** → `chat.html` 전체화면 챗.

### 딥링크

슬라이드 챗 답변의 `재고현황에서 열기 ↗` 를 누르면 뒤의 ERP 화면이 **로트별 재고현황**으로 전환되고,
해당 로트(`L-2607-18`) 행이 하이라이트되며 상단에 이동 배너가 뜬다. LNB active도 재고정보 관리로 옮겨간다.

## 응답 규격

AI 답변은 기획서에 확정된 JSON 규격을 전제로 만들었다.

```json
{
  "query": "이번 달 A라인 불량률은?",
  "sources": ["production_db", "quality_db"],
  "answer": "이번 달 A라인 불량률은 1.8%입니다.",
  "confidence": "high"
}
```

`sources`는 답변 하단 근거 칩으로, `confidence`는 배지로 노출된다 (high 조용 / medium 확인 / low 강조 축소).

## 로컬 실행

```bash
python3 -m http.server 4173
```

브라우저에서 http://localhost:4173 을 연다.

## 메모

- 외부 의존은 Pretendard 웹폰트 CDN 하나뿐이고, 나머지는 전부 상대경로다.
- 데이터는 전부 목업이다. 실제 ERP DB나 Azure OpenAI에 붙지 않는다.
